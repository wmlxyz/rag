# 50 会话 Query Rewrite 对照结果

## 数据与方法

按照 [实验方案](rewrite_50_protocol.md)，从具有可匹配证据的 68 个会话中随机选取 50 个，每个取首个合格追问；排除了先前 Query Rewrite 实验的会话。固定 1149-passage 受限候选池、3009 个切片、FAISS HNSW、Top-K=5、4000 字符证据预算、`qwen-plus` 和 `text-embedding-v4`。历史最多 8 条消息，包含 QReCC 提供的历史人工改写和参考答案。三组分别使用当前问题、历史拼接和模型改写，均使用相同参考历史来生成回答；没有启用 Reranker 或缓存。

150 次问答全部成功，三组各 50 条有参考答案及可匹配来源标注。改写调用 50 次，无记录到的改写回退；过程中出现的网络重试不等同于最终失败。结果的源码哈希与运行结束时一致。

## 汇总结果

| 指标 | 当前问题 | 历史拼接 | Query Rewrite |
|---|---:|---:|---:|
| Hit@5 | 27/50（54%） | 49/50（98%） | 49/50（98%） |
| MRR@5 | 0.4323 | 0.8690 | 0.8923 |
| 回答 Token F1 | 0.2293 | 0.3367 | 0.3319 |
| 完全匹配 | 0/50 | 0/50 | 0/50 |
| 引用编号有效 | 40/50 | 45/50 | 43/50 |
| 平均总耗时 | 4.87 秒 | 6.37 秒 | 6.64 秒 |
| P95 总耗时（最近秩） | 10.02 秒 | 11.97 秒 | 12.77 秒 |

命中和 MRR 是参考 passage **来源级**指标，并不证明被送入上下文的 chunk 确实包含正确答案。F1 为项目内的词面重合指标，不是官方 QReCC 评分，不保证语义正确。引用指标只检查编号存在且无错误编号，不验证证据支持性；全为零的完全匹配不能解释为所有回答错误。延迟含远程网络、模型调用和检索；三组串行执行，网络重试和服务负载可造成波动，不能将延迟差全部归因于方法。

## 配对比较

以相同问题配对、按会话 bootstrap 5000 次的 95% 百分位区间如下：

| 比较（前者减后者） | Hit@5 差值 | MRR@5 差值 | 答案 Token F1 差值 |
|---|---:|---:|---:|
| 历史拼接 − 当前问题 | +0.440 [0.300, 0.580] | +0.437 [0.285, 0.586] | +0.107 [0.065, 0.156] |
| 改写 − 当前问题 | +0.440 [0.300, 0.580] | +0.460 [0.334, 0.586] | +0.103 [0.059, 0.152] |
| 改写 − 历史拼接 | 0.000 [−0.060, 0.060] | +0.023 [−0.055, 0.107] | −0.0048 [−0.0240, 0.0133] |

区间只描述此覆盖筛选样本及受限候选池下的抽样波动；它不能修复选样和候选池偏差。改写与历史拼接的区间包含 0，不能据此断言两者有稳定差异，也不能证明二者等效。

## 个案与错误

有 22 条在仅用当前问题时未命中，而改写后命中。例如 `test:1073:3` 问“Did it have any hits?”，改写后补全为询问 Ratt 的专辑 *Dancing Undercover* 是否有热门歌曲，两种结合历史的方法均命中标注来源。

但改写也可能改变任务：`test:1871:4` 原问题为“她的一张专辑叫什么？”，模型输出的检索 Query 是 `Concentration 20`，更像直接给出一个答案，而不是完整问题；该条改写组未命中标注来源。对照中改写相对历史拼接，标注来源首个命中的倒数排名有 7 条上升、5 条下降、38 条不变；没有对全部改写做人工忠实度标注，不能把这些排序变化直接等同于改写正确或错误。

## 调用与限制

模型返回的生成 Token 共：当前问题 55,884，历史拼接 63,072，改写组 62,841；改写组另有 8,201 改写 Token。没有记录 Embedding 用量、重试请求数量和实际价格，因此不能计算完整费用。无效引用编号分别出现 5、5、6 条，部分回答同时还有有效编号，因而与无有效引用数量存在重叠。

问题是在 200 个随机测试会话中按证据可得性筛选出的；候选池包含依赖测试标注选出的正例和来自语料前缀的干扰片段。筛选让本实验可进行来源级配对比较，但很可能高估总体覆盖或检索表现；结果不代表完整 QReCC 开放域。参考历史包含人工改写和参考回答，也不同于系统自身生成的真实历史。下一步需要预先固定不依赖覆盖率的会话样本、扩大独立候选池和标注覆盖，核对 ANN 与精确检索，并对改写和回答进行人工盲评。
